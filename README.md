## Dieses Projekt dient zur Modernisierung und Automatisierung des Aufsteh prozesses
   - Der Geschreibene Code würde für den Shelly 2.5 geschireben und kann nach belieben bearbeitet werden

## Automatision des Scripts:
   - Divera Alarm 
     - Alarmierung durch Divera erfolgt und wird erkannt
     - Licht wird eingeschaltet
     - Licht schaltet sich nach 30 sek aus

   - Wecker Funktion
      - Vorherige eingestellte Weckzeot wurde erreicht
      - Licht 1 & 2 werden mit ein 0.2
